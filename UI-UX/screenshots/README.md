# Screenshots

Empty until captured. See `../09-SCREENSHOT-CHECKLIST.md` for the full shot
list, the exact filename each shot should use, and capture instructions.

## Conventions

- **PNG**, no compression artefacts
- **Desktop: 1440×900**, **Mobile: 390×844**
- Real-looking content — avoid "asdf" and lorem ipsum; the designer needs to
  see how real names, real message lengths and real timestamps behave
- Do not crop out the surrounding chrome unless the filename says "close crop"
